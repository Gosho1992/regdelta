What each finding type means

Missing element
The asset produces an affected template but the new field or rule is not in it. Checked: the element is absent from the file.
Direct reference
The file names the changed field, its internal column, the rule ID or the old format, on the line shown.
Upstream feeder
Builds a table a report reads from, so a new field has to flow through it.
Downstream
Consumes the output of a directly affected asset (table lineage or a Python import).
Semantic candidate
Mentions related wording but never references the field. Possibly affected. Never confirmed without a human.

How the approval gate works

Fingerprint
SHA-256 over both specs, every scanned asset and every finding. Shown in the header.
Blocked when
No approval, malformed approval, an agent as reviewer, a missing decision, or anything changed since the human approved.
Opens when
The Human Reporting Owner's decisions cover every finding of this exact assessment.
Never
RegDelta never edits the reporting assets. It produces a plan for people.
